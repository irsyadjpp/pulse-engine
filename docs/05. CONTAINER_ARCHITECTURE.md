# 1. Purpose

Dokumen ini mendefinisikan arsitektur aplikasi Pulse Engine berdasarkan C4 Model Level 2 (Container Diagram).

Tujuan dokumen ini adalah:

* Mengidentifikasi seluruh container dalam Pulse Engine.
* Mendefinisikan tanggung jawab masing-masing container.
* Menjelaskan hubungan antar container.
* Menjadi dasar implementasi microservices.
* Menjadi referensi Integration Architecture dan Deployment Architecture.

Dokumen ini tidak membahas detail implementasi internal setiap container.

---

# 2. Container Overview

Pulse Engine terdiri dari beberapa container yang bekerja sama untuk menyediakan layanan marketplace Personal Accident Insurance.

Container dikelompokkan berdasarkan domain bisnis.

```text id="d4r8qy"
Pulse Engine

├── Presentation Layer
├── API Layer
├── Customer Domain
├── Product Domain
├── Sales Domain
├── Payment Domain
├── Policy Domain
└── Platform Domain
```

# Appendix B. Container Summary

Pulse Engine terdiri dari container yang dikelompokkan berdasarkan domain bisnis.

Setiap container memiliki tanggung jawab tunggal dan berkolaborasi untuk mendukung proses bisnis mulai dari pengelolaan produk hingga penerbitan polis.

Container Architecture ini menjadi dasar untuk penyusunan **Component Architecture**, yang akan menguraikan struktur internal setiap container beserta komponen-komponen utama di dalamnya.
