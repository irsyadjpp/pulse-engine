# 1. Purpose

Dokumen ini mendefinisikan Domain Event yang terjadi selama proses bisnis Pulse Engine.

Event Storming digunakan untuk:

* Memahami alur bisnis secara end-to-end.
* Mengidentifikasi Domain Event.
* Mengidentifikasi Command.
* Mengidentifikasi Aggregate.
* Mengidentifikasi Actor.
* Mengidentifikasi Policy.
* Mengidentifikasi Read Model.
* Menjadi dasar desain event-driven architecture.

Dokumen ini tidak membahas implementasi teknis, broker pesan, ataupun protokol komunikasi.

---

# 2. Event Storming Legend

| Element      | Description                                                  |
| ------------ | ------------------------------------------------------------ |
| Actor        | Pengguna atau sistem yang memicu proses bisnis.              |
| Command      | Permintaan untuk melakukan suatu aksi bisnis.                |
| Aggregate    | Objek bisnis yang menerima command.                          |
| Domain Event | Fakta bisnis yang telah terjadi.                             |
| Policy       | Aturan bisnis yang merespons suatu event.                    |
| Read Model   | Data yang digunakan untuk kebutuhan pembacaan atau tampilan. |
